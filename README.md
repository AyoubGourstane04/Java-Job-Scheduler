# Job Scheduler & Worker Pool

A Java 21 project implementing a multithreaded job scheduler with priority-based execution and a worker pool.

## Features
- Concurrent job execution using worker threads
- Priority scheduling (HIGH, MEDIUM, LOW)
- Automatic retries with exponential backoff
- Job timeouts and cancellation
- Graceful shutdown and job status tracking

## Technologies
- Java 21
- Java Concurrency API

## Run
Open the project in your Java IDE and run the `Main` class.

## Concepts
Multithreading, synchronization, concurrent collections, thread interruption, and scheduled tasks.
